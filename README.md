# ICT251 Activity 2 - Personal Web Portfolio

A structured, responsive personal portfolio website developed for the **ICT251: Web Technologies I** course at **Mulungushi University**.

## 📌 Project Overview

This project demonstrates core Web Technology concepts including:
- Semantic HTML5 structure (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`)
- Clean document outline with hierarchical headings (`<h1>`, `<h2>`, `<h3>`)
- Multimedia integration using HTML5 `<video>` and `<audio>` controls with full fallback text and written transcripts
- CSS layout styling linked via relative paths
- Structured data presentation using HTML tables and forms
